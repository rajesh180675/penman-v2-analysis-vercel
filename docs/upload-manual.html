1. Overview: Two Ways to Load Data

The app has two paths to get financial data into the valuation engine:

Path A — Library Card

Click any of the 13 pre-loaded companies. Everything is automatic — consolidated ZIP, standalone ZIP, quality sidecar, and config are all fetched for you.

Best for: Exploring the tool, testing pipelines, learning what the output looks like.

Path B — Custom Upload

Upload your own Capitaline exports for any Indian listed company. You control what goes in.

Best for: Analyzing companies not in the library, using fresh data you just exported.

3. Path B: Custom Upload (Your Own Company)

For companies not in the library, scroll past the grid to the "Upload Capitaline Data" section. This has 3 upload slots plus a configuration row.

4. Step 1 — Fill the 4 Essentials

Before uploading any file, fill the configuration row at the top of the upload card:

FieldWhat to enterRequired?
Company ID Short identifier (e.g. BAJFINANCE, HDFCBANK). Used in audit trail. Yes
Company Type Select from dropdown: Bank, NBFC, Insurance, Industrial, IT Services, Consumer/FMCG, Utility/PSU, Telecom, Cyclical/Metals Yes ⛔
Market Price ₹ Current stock price (for P/E, P/B, fair value gap). Leave blank if unknown. Recommended
Shares (Cr) Shares outstanding in crores. Auto-detected from data if blank. Optional
Company Type is mandatory. The upload drop zone is disabled (red border, grayed out) until you select a type. This determines which valuation pipeline runs — Bank pipeline for banks, Penman-Nissim recast for industrials, etc.
Use the explicit type you know the company IS. Don't rely on auto-detection — the tool uses your declaration to route to the correct pipeline.

5. Step 2 — Upload Consolidated ZIP

1 Consolidated Financial Data Required

This is the main data source. A single ZIP file containing 3 Capitaline XLS exports:

  • Balance Sheet (Ind AS Detailed)
  • Profit & Loss (Ind AS Detailed)
  • Cash Flow Statement

How to upload:

  1. Drag & drop your ZIP file onto the dashed drop zone, OR
  2. Click the drop zone to open a file browser

After dropping, you'll see a progress stepper:

  1. Extracting Files — decompressing the ZIP
  2. Reading Formats — mapping XLS sheets and columns
  3. Balancing NOA/NFO — aligning assets & liabilities
  4. Dataset Ready — pipeline compiled, dashboard opens
If you pre-loaded a Standalone ZIP (Slot 2) before uploading the Consolidated ZIP, the standalone is automatically parsed first and fed into the gap analysis pipeline.

6. Step 3 — Upload Standalone ZIP (Optional)

2 Standalone Statements Optional

A separate ZIP with the same 3 files (BS + P&L + CF) but from the standalone financial statements.

Purpose: Enables subsidiary contribution gap analysis. The engine computes: Consolidated − Standalone = Subsidiary Contribution

How to upload:

  1. Drag & drop a standalone ZIP onto the smaller drop zone, OR click it
  2. Once loaded, you'll see: ✓ filename.zip (size KB) with a "Remove" button
  3. The file is held in memory until you upload the Consolidated ZIP (Slot 1)
Load the standalone BEFORE the consolidated. When you drop the consolidated ZIP, the app automatically parses standalone first, then runs the full dual-scope pipeline.
Do NOT mix consolidated and standalone files in the same ZIP. They use identical sheet structures — combining them causes naming collisions and data overwrites.

7. Step 4 — Upload Quality Sidecar (Bank/NBFC Only)

3 Quality Indicators Sidecar Bank/NBFC/Insurance

A JSON file with pre-computed bank quality metrics that Capitaline doesn't export in standard XLS format.

Purpose: Enables NIM, GNPA, CRAR, Cost/Income, Yield, Spread panels on the Bank tab.

This slot only appears when Company Type = Bank, NBFC, or Insurance.

What the JSON should contain:

FieldDescription
schema_version"2026-05-bank-quality-v1"
company_nameFull legal name
as_of_dateLatest period end (e.g. "2025-03-31")
periods[]Array of yearly objects with NIM, GNPA, CRAR, cost_to_income, yield_on_advances, cost_of_borrowings, spread, etc.
If you don't have this file, the dashboard still works — it just won't show bank-specific quality panels (NIM chart, Asset Quality table, etc.). The valuation models still run using computed fallbacks.

9. What Happens After Upload

Once the consolidated ZIP is processed successfully:

  1. The progress stepper shows all 4 steps green ✓
  2. A success banner appears: "Excellent! [filename] was ingested successfully."
  3. The dashboard auto-opens with:
    • Buy/Hold/Avoid verdict
    • Narrative summary
    • ~12 charts (profitability, valuation, quality, etc.)
    • Bank tab (if type = bank/nbfc) with NIM, ROA, Asset Quality
    • Scope tab (if standalone was loaded) with subsidiary contribution

10. How to Prepare the Capitaline ZIP

Step-by-step in Capitaline:

  1. Log in to Capitaline Plus
  2. Search for your company
  3. Go to Financials → Balance Sheet → Ind AS Detailed
  4. Click Export → XLS — filename must contain the word balance
  5. Go to Financials → Profit & Loss → Ind AS Detailed
  6. Click Export → XLS — filename must contain profit or pnl
  7. Go to Financials → Cash Flow
  8. Click Export → XLS — filename must contain cash
  9. Select all 3 XLS files → Right-click → Send to → Compressed (zipped) folder
  10. Upload the resulting ZIP
Scope rule: Export either ALL Consolidated or ALL Standalone. Never mix them in one ZIP. The parser uses identical column structures for both — mixing causes silent data overwrites.

Filename detection rules:

StatementFilename must containExample
Balance SheetbalanceHDFC_Balance_Sheet_2025.xls
Profit & Lossprofit or pnlHDFC_Profit_Loss_2025.xls
Cash FlowcashHDFC_Cash_Flow_2025.xls

Debug trace

Every upload action is logged to the trace system. To export the debug trace:

  1. Open the Debug tab in the dashboard
  2. Click Export Trace JSON
  3. The JSON file contains every step: parse/processZip:start, parse/standaloneZip:success, quality/sidecarUpload:error, etc.
